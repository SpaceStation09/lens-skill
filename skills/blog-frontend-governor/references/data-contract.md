# Data Contract v1

## Account State Machine

`AccountState` has exactly 3 values:

1. `disconnected`
2. `connected_unauthed`
3. `authenticated`

State transitions:

1. `disconnected -> connected_unauthed`: wallet connected
2. `connected_unauthed -> authenticated`: selected account login success
3. `authenticated -> disconnected`: wallet disconnected

## Core View Models

### `WalletAccountOption`

```ts
{
  address: string;
  handle?: string;
  displayName?: string;
}
```

### `ProfileView`

```ts
{
  address: string;
  handle: string;
  displayName: string;
  bio: string;
  avatarUrl?: string;
  followers?: number;
  following?: number;
}
```

Rules:

1. `handle` should be normalized without `@` prefix
2. `avatarUrl` optional; if missing, UI must render address-based identicon
3. `followers/following` are optional; hide when absent

### `PostView`

```ts
{
  id: string;
  createdAt: string;
  title: string;
  excerpt: string;
  content: string;
  tags: string[];
  authorAddress: string;
  contentUri?: string;
}
```

Rules:

1. `excerpt` should be generated by mapper (not in render layer)
2. `tags` must come from Lens metadata tags when available
3. UI list page should use `excerpt` instead of raw full content

## Adapter Interface

Template app depends on `LensBlogAdapter` only and must not call Lens SDK directly from presentation layer.

```ts
interface LensBlogAdapter {
  getWalletAccounts(ownerAddress: string): Promise<WalletAccountOption[]>;
  loginWithAccount(accountAddress: string): Promise<{ handle?: string; address: string }>;
  getProfileByHandle(handle: string): Promise<ProfileView>;
  getProfileByAddress(address: string): Promise<ProfileView>;
  getPostsByAuthor(authorAddress: string): Promise<PostView[]>;
  publishPost(input: PublishInput): Promise<void>;
}
```

## Theme Config Contract

Theme selection should be config-driven:

```ts
{
  themeId?: "default";
}
```

Rules:

1. If `themeId` is missing or invalid, resolve to `default`
2. Theme rendering must come from theme package (no ad-hoc switch in app page component)
3. New theme should be published/linked as independent package (`@lens-blog/theme-*`)
4. Host app may inject external `theme` object (from local/npm package)
