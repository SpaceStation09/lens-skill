# lens-blog Agent Skill

本 skill 用于指导 Cursor Agent 使用 Lens Protocol SDK 搭建基于 Lens 的个人博客系统。

## 使用场景

当用户提到以下任一情况时，Agent 应自动应用此 skill：

- 使用 Lens SDK 搭建博客
- 在 Lens 上发布文章
- 基于 Lens Protocol 的去中心化博客
- Lens 个人博客系统

## 文件说明

- **SKILL.md** - 主指导文档，包含核心流程和代码示例
- **reference.md** - 详细 API 参考，供需要时查阅

## 安装位置

- 项目 skill: `.cursor/skills/lens-blog/`（已配置）
- 副本: `skills/lens-blog/`（可提交到版本控制）
